HEN PORTFOLIO - הוראות העלאה

1. פתחי את ה-ZIP (Extract) כך שתהיה תיקייה עם index.html
2. היכנסי ל-https://app.netlify.com/drop
3. גררי את התיקייה לחלון - תקבלי קישור חי תוך שניות
4. כדי לשמור את האתר קבוע: צרי חשבון חינמי ב-Netlify

אפשרויות נוספות: GitHub Pages, Vercel, Cloudflare Pages (כולם חינמיים)

עריכת תוכן: פתחי את index.html בעורך טקסט (או VS Code) וחפשי את כותרות הפרויקטים והטקסטים.
חשוב: התמונות כרגע נטענות מהאתר הישן שלך ב-Wix. כדאי להוריד אותן לתיקייה images/ ולשנות את הנתיבים, כדי שהאתר לא יישבר אם תמחקי את אתר ה-Wix.
